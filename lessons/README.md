# 算法小课堂

每讲使用独立目录和静态 HTML，共用 `lesson.css`、`lesson.js`。不需要构建工具或远程字体、脚本；支持完整讲义、逐页演示、目录跳页、讲者提示、全屏、打印与引用跳转。

第一讲共有 21 页主讲内容和 2 页附录，按实际课堂讲解重排。URL 加 `?present=1` 可直接进入演示模式，保留 `#proof` 等章节锚点。讲者提示通过原生对话框查看，Esc 先关闭提示，再按一次退出演示。

字体随站点提供：中文 Noto Sans SC，数学表达 STIX Two Text。正文使用 19px / 1.85 行高，中文标题不压缩字距；演示模式独立放大，窄屏双栏改为单栏。新增讲次时同步更新字体子集，见 `fonts/README.md`。

## 后续讲次

1. 阅读手写笔记，确认页序与论证主线。保留作者的问题与推理，避免扩写成通用百科。
2. 核对历史与技术事实，优先原始论文、机构资料和官方文档。引文贴近相应主张，区分教学简化、作者观点与可验证事实。
3. 新建 `02-<topic>/index.html`，沿用第一讲的页面头尾。正文各节使用 `section.slide`、唯一 `id` 与简短 `data-title`。
4. 每页围绕一个问题。正文用于讲解，`details` 放补充说明。适合过程讲解的地方加入可操作演示。
5. 加入参考资料与必要的核对说明。更新主页 Classroom 和 sitemap，不预先创建空白后续页面。
6. 校验算法与数值示例、HTML 本地路径和锚点、JavaScript 语法。保留其他工作区的未提交改动。按用户指定的现有 GitHub Pages 发布流程交付。

## 第一讲的约定

- 数学输入为两个正整数。递归内部允许第二个参数为 0；不讨论 (0,0)。
- 演示限制 1–9999，开始前排序，交换不计步数；一次取余或减法各算一步。
- 相等时减法继续到零，因此 (26,6) 为 2 次取余、7 次减法；若改用相等即停的另一版本，减法计数会不同。
- 这是基本操作计数示例，不是位复杂度或实际时延测量。
- 原始手写照片仅作为整理输入，不发布包含私人环境的照片。

## 演示维护

- 每页只推进一个教学步骤。先解释符号，再给例子，最后展开证明。关键推理应直接可见，讲者提示只放提问、节奏和补充说明。
- `(26,6)` 贯穿问题定义、取余、正确性、终止性与效率比较，避免每页换一个例子。
- 长演算只显示最近 4 个状态，初始状态编号为 0，后续编号对应操作次数。可逐步、前进 1000 步或运行到底。
- 所有正文页在 1280×720 的演示模式下应完整显示，按钮与结果不得落到固定页脚后面。手机允许纵向滚动，不允许横向溢出。
- 发布时只包含整理后的教学内容，不上传课堂逐字稿、参与者信息或录音。
