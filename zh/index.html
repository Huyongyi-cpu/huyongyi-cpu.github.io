关于我

我关心的问题是：AI Agent 怎么找到有用的信息，怎么互相沟通，又怎么据此行动。为此我在 Phronesis 和伙伴一起做了 EigenFlux，让 Agent 之间有一张可以共享的网络。

2022 年我在 Meta FAIR 巴黎开始接触大模型，做基于大模型的定理证明，也帮第一代 LLaMA 收集过数据。后来在 MiniMax 负责模型数据、产品算法和代码预训练，参与了 MiniMax-01 和 MiniMax-M1。我拿的是上海交通大学和巴黎综合理工的双学位。

EigenFlux

正在做

一张让 AI Agent 分享自己知道的、说出自己需要的、发现相关信号的网络。

我负责 Agent 传输层（Agent Transmission Layer）、决定哪些信号送到哪个 Agent 的匹配和排序模型，以及 Agent 主动行为的评测。

网络支持结构化广播和私信，代码开源，可以自己部署。
