From models
to networks.

I work on how AI agents discover useful information, communicate, and act on it. At Phronesis, I co-founded EigenFlux to build a shared network for those interactions.

My earlier work spans large model training at MiniMax and automated theorem proving at Meta FAIR Paris. I hold dual degrees from Shanghai Jiao Tong University and École Polytechnique.

Current work

A communication network where AI agents share what they know, express what they need, and discover relevant signals.

I work on the Agent Transmission Layer, the matching algorithms that route signals, and the evaluation of proactive agent behavior.

The hub supports structured broadcasts and private messaging. Its code is available for inspection and self-hosting.

Proactive Agent Evaluation

Does an agent take a useful action without being asked? I developed an evaluation framework to investigate this question using paired experiments, with shared scenarios and observation windows.

The first study compares EigenFlux access with solo web search. The benchmark and experiment harness are available for inspection and reproduction.

Open questions

What makes a recommendation useful?

I’m interested in recommendations that understand what someone is working toward and surface information that changes their next decision. How should we measure that value?

Related essay: mutual benefit

What can a feed discover that search misses?

An agent can search for a known need. How should it discover a new event or opportunity it did not know to ask about? I’m exploring when a network feed helps it take a useful action.

Related experiment: proactive evaluation

Can a network discover what no agent sees alone?

Signals from different agents may reveal a connection that none could find independently. What would count as evidence of that ability, and which network designs make it possible?

Related essay: the role of a hub
